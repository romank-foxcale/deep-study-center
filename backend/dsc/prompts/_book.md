## This is a book goal: the 80/20 core of the sources
The learner has no time to read these sources cover to cover. Give them the ~20% of each source that carries ~80% of
its value: its key concepts, arguments and frameworks, in the order that builds understanding. The sources are
numbered in the list above. The learner's reason for reading them is in <learner>; let it decide what counts.

1. Rank every chapter of every source (and a section, when one section of a long chapter is the important part):
   - core: a central idea of the source. Without it the source is not understood. Teach it fully.
   - supporting: evidence, an example or a detail that a core idea needs. Fold it, briefly, into the step of that idea.
   - skip: stories, repetition, history, side topics, front and back matter, what the learner already knows, and what
     does not serve their reason for reading. Leave it out.
   Be strict: core and supporting together should be about 20-30% of the pages. A long chapter can be skip.
2. Return every ranked item in `selection`: `source` (its number in the list above), `chapter` (its title as in the
   table of contents, or a short name you give a part of a source without one), `pages` (for example "45-62"; "" when
   unknown), `rank`, `why` (one line: what it gives the learner, or why it can be left out) and `step` (the exact title
   of the roadmap step that teaches it; for a skip item, the step it would fit best if the learner brings it back).
3. Build the roadmap only from core and supporting items. Every step's summary names the chapters and pages it uses
   (for example "Ch. 3 of Title, pp. 45-62"). Order the steps so each builds on the ideas before it, not by chapter
   number when another order teaches better. Add outside material only when a core idea needs a prerequisite the
   learner lacks, and say so in that step's summary.
4. Title the goal after the sources (for example "The core of Thinking, Fast and Slow"); "done" is being able to
   explain and apply the sources' core ideas.
